
Intel Mac環境において、UTM上で AlmaLinux 9（や Rocky Linux 9）の仮想マシンを構築する際、ストレージ設定やインストールの最終段階で以下のエラーが発生して中断されることがあります。

> `resource to create this format macefi is unavailable`

この問題は、UTMの仮想化設定と Red Hat 系 Linux のインストーラー（Anaconda）が、Mac固有のブートローダー（`macefi`）を自動作成しようとして競合を起こすことが原因です。

本記事では、**VirtIO による高速 I/O パフォーマンスを維持したまま、このエラーを確実に回避して環境を構築する手順**を解説します。

---

## 1. 【大前提】Intel Macでは「QEMU」を使用する

UTMの新規作成画面では **「Apple仮想化を使用」** を選択せず QEMU を使用してください。

* **理由**: Apple仮想化機能は主に Apple Silicon (M series) 向けに最適化されており、Intel Mac 環境では動作が不安定になる原因となります。
* **パフォーマンスについて**: Intel Mac 上で x86_64 アーキテクチャの Linux を動かす場合、QEMU であってもホスト CPU のハードウェア支援機能（VT-x）が直接有効化されます。そのため、ほぼネイティブに近い速度で動作します。

---

## 2. 高速化のための VirtIO 設定

互換性優先で `IDE` や `e1000` などのレガシーデバイスを選択すると、ディスク I/O やネットワーク速度が大幅に低下します。

起動前に仮想マシンの**「詳細設定（Edit）」**を開き、以下の通りインターフェースを設定してください。

### ① ドライブ設定（VirtIO）
1. 仮想マシン設定の **「ドライブ」** を開きます。
2. AlmaLinuxをインストールする空の仮想ディスク（例: 32GB）を選択します。
3. インターフェース（Interface）を **`VirtIO`** に設定します。

### ② ネットワーク設定（virtio-net-pci）
1. 設定の **「ネットワーク」** を開きます。
2. ネットワーク方式は **「共有ネットワーク（NAT）」** のままで問題ありません。
3. デバイス（Emulated Network Card）で **`virtio-net-pci`** を選択します。

---

## まとめ

以上の設定により、Intel Mac の CPU パワーと VirtIO の高速 I/O を最大限に活かした、快適で安定した AlmaLinux 9 環境を構築できます。
